# OpenStream100
A Linux-compatible driver and PipeWire mixer for the Hercules Stream 100, with
Mixer, Full-screen image, and editable Notepad display modes.
Notepad supports saved font sizing, family, style, text colour, and alignment.
The resizable desktop mixer mirrors the hardware layout and remains usable when
the controller is disconnected.

The companion OpenStream100 Remote Android app provides the same four-channel
mixer on a phone. It supports local-network discovery, GUI-approved PIN pairing,
QR fallback, saved per-device credentials, application icons, live meters,
smooth faders, mute controls, page navigation, and programmable buttons.

Installable RPM, Debian, Arch Linux, and Android APK packages are available from
the GitHub Releases page.
