# OpenStream100 0.18.2

This Linux release adds optional lock-screen protection for the Hercules
Stream 100 display and controls.

## Highlights

- Adds **Protect controls while PC is locked** to the Display tab.
- Uses the desktop-neutral systemd-logind session lock state rather than a
  KDE-, GNOME-, or COSMIC-specific API.
- Turns the controller backlight fully off while the desktop session is locked.
- Ignores encoder movement, knob presses, and numbered-button actions while
  locked, without replaying that input after unlock.
- Rejects authenticated mobile-remote commands while locked and reports the
  protected state to remote clients.
- Restores the current display mode at the saved brightness after unlock.
- Leaves protection disabled by default for existing installations.

Lock detection requires systemd-logind and a desktop locker that updates the
session's `LockedHint`. KDE Plasma, GNOME, and COSMIC use this shared session
interface; minimal window-manager setups depend on their selected locker.
