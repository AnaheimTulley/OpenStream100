# OpenStream100 0.17.1

This release adds the OpenStream100 Remote Android app and completes the Linux
host-side pairing workflow.

## Highlights

- Four-channel Android mixer with smooth faders, live meters, mute controls,
  page navigation, programmable buttons, and assigned application icons.
- Automatic local-network discovery using mDNS.
- GUI-approved six-digit PIN pairing for new phones, with QR pairing retained as
  a fallback.
- Hashed per-device credentials, individual device revocation, and automatic
  reconnection for already paired phones—even when the host address changes.
- OpenStream100 launcher artwork on the Android app and fader display.

attached. Verify downloads against `SHA256SUMS`.

## Android pairing

Enable the Android remote in the OpenStream100 Linux control panel, then select
the discovered computer in the phone app. Enter the PIN shown automatically by
the desktop GUI. Previously paired devices reconnect without another PIN.

Both devices must be on the same trusted local network. If discovery or pairing
cannot connect, allow TCP port `47680` through the Linux firewall. QR pairing is
available from the control panel as a fallback.
