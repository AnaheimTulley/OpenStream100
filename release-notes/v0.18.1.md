# OpenStream100 0.18.1

This Linux feature release adds system monitoring, a system-tray indicator,
live display previews, and a streamlined control panel.

## Highlights

- Reorganises the Linux control panel into Mixer, Buttons, Display, and Android
  app tabs, with page management in Mixer and service controls always available.
- Adds a System Monitor display with configurable live CPU, GPU, memory, disk, and
  available temperature readings while all mixer controls remain operational;
  audio-only white volume markers are omitted from this mode.
- Shows only the settings relevant to the selected display mode.
- Automatically checks GitHub for a newer stable release when the control panel
  opens, then no more than once every 24 hours.
- Adds a manual **Check for updates** button beside the installed version.
- Adds a persistent system-tray indicator with control-panel and mixer-service actions.
- Adds a live 480×272 control-panel preview for unsaved display changes.
- Adds selectable OpenStream and Hercules mixer badge styles; Hercules Style
  centres a larger icon and briefly replaces the app name with the volume after
  a change.
- Shows a clear **View release** banner when an update is available.
- Keeps GitHub requests off the GTK thread so slow or unavailable networking
  cannot freeze the control panel.
- Caches the last check, release details, and `ETag` to minimise network use.
- Handles offline and rate-limited automatic checks quietly without affecting
  mixer operation.
- Never downloads or installs a package automatically; installation remains
  under the user's package manager and administrator control.
