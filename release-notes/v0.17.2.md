# OpenStream100 0.17.2

This Linux maintenance release adds guided calibration for Stream 100 units
whose knob presses mute the wrong mixer channels.

## Highlights

- New **Knob mute calibration** section in the Linux control panel.
- Clear four-step prompts to press each knob straight down in order.
- Automatic mixer pause and restart so calibration can claim the USB controls.
- Existing assignments, pages, colours, display options, and other settings are
  preserved.
- Separate numbered programmable buttons are rejected during knob calibration.
- The existing terminal-based `--calibrate-buttons` workflow uses the same
  clearer knob-press wording and validation.

## Downloads

- Fedora 44 x86_64: `hercules-stream100-0.17.2-1.fc44.x86_64.rpm`
- Debian/Ubuntu amd64: `hercules-stream100_0.17.2-1_amd64.deb`
- Arch Linux x86_64: `hercules-stream100-0.17.2-1-x86_64.pkg.tar.zst`
- Android 8.0 or later: `openstream100remote.apk` (unchanged from 0.17.1)

The checksummed source archive used by the Linux package recipes is also
included. Existing installations only need calibration if pressing a knob mutes
the wrong channel.
