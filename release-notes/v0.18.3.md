# OpenStream100 0.18.3

This release adds quick display-mode switching from the Linux system tray and
improves mobile-app installation from the control panel.

## Highlights

- Choose Mixer, Full-screen image, Notepad, or System monitor from the tray's
  **Display mode** submenu. The menu shows the saved selection.
- Switching mode preserves saved artwork, notes, monitor sources, and mixer
  settings. A running mixer restarts to apply the selection; a stopped mixer
  stays stopped.
- The **Remote (Phone App)** tab groups remote access, Android installation,
  and iOS installation into separate sections, with setup checks, progress,
  and cancellation.
- Linux packages bundle the Android APK and iOS source with its Xtool installer.
- Improves macOS configuration handling for duplicate channels and non-finite
  values; core tests can also run on Linux.
- Updates Android and platform setup documentation.
